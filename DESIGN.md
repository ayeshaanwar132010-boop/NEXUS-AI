# NEXUS AI UI design
- Subject: local-first autonomous intelligence command center.
- Palette: midnight #090B14, surface #111626, violet #A997FF, cyan #69E7F1, mint #6BE6B4.
- Typography: Inter/system UI, DM Mono for telemetry.
- Signature: orbital intelligence core, with motion used only for hierarchy and system-state cues.
- Responsive sidebar becomes a mobile drawer; cards preserve content and actions.
- Reduced motion is respected. Focus indicators remain visible.
- Execution is a local demonstration, never represented as an external action.
